# Lanternmere — character portraits

Hello! This file is everything you need to paint **81 character portraits** (27 characters × 3 expressions) for **Lanternmere**, a cosy, mysterious witch-academy story game. Please read it all first, then work through it in order.

## Attached with this file

- `c01-rowan-neutral.png` and `c02-imogen-neutral.png` — **style references.** Every new portrait must look like it belongs in the same game as these two.

## Style rules (every image)

1. **Exactly the same art style as the references:** the same dense painterly pixel texture, warm lighting, colour palette and level of detail.
2. **Same framing:** three-quarter upper-body pose (head, shoulders and upper chest), the same scale and position as the references, canvas **1122×1402** pixels, portrait orientation. Keep the whole head and hair inside the canvas.
3. **True transparent background** (PNG with alpha). No backdrop, no shadow box, no floor.
4. **One character per image.** No text, no names, no frame, no border, no collage, no grids of options.
5. Everyone is an **adult**. Clothing is warm, slightly old-fashioned academy and village wear, with no modern items.
6. Follow each character's description closely (skin tone, hair, clothing, props). Don't add animals, weapons or extra props that aren't described.

## How to work

1. **For each character, make three images:** `neutral` first, then `warm`, then their **signature** expression (listed per character).
2. **The three images of one character must be the same person:** identical face, age, hair, clothing, accessories, lighting, pose, scale and framing. Only the facial expression (and the tiny head or eye movement it needs) changes. Create the neutral first and base the other two on it.
3. **Name every file exactly as listed** (lower-case, hyphens, `.png`). The game finds each image by its filename, so a wrong name means the image won't appear.
4. **Pace:** do one character (3 images) or a few characters at a time, in the order below, and give me each image as a downloadable PNG with its filename. When you stop, tell me which character is next. When I say **"continue"**, carry on from there.
5. If a description seems contradictory or unclear, make a sensible choice that matches the cosy style. Don't stop to ask.

Expression guide:

- **warm** — a soft, genuine, friendly smile
- **amused** — a small amused smile, eyes bright
- **laugh** — mid-laugh, open and joyful
- **grave** — serious and solemn, mouth set
- **tense** — tense and worried, brow drawn
- **tired** — tired but kind, heavy-lidded, a faint smile
- **hurt** — hurt and apologetic, eyes lowered
- **shy** — shy, a little bashful, glancing aside
- **surprised** — surprised, eyebrows raised, lips parted
- **scared** — startled and anxious, eyes wide
- **attentive** — listening closely, focused and engaged
- **reflective** — thoughtful, looking slightly away
- **guarded** — guarded and wary, chin slightly lifted
